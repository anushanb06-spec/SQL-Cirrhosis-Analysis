# Cirrhosis Data Analysis Using SQL

## Project Overview
This project focuses on analyzing cirrhosis patient data using SQL queries to explore patient information and identify patterns in the dataset.

## Tools Used
- MySQL
- MySQL Workbench

## Project Objectives
- Analyze cirrhosis patient data.
- Retrieve and filter patient records.
- Explore patient characteristics and clinical information.
- Practice SQL queries for data analysis.

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- Filtering
- Joins

## Project Process
1. Imported and explored the dataset.
2. Wrote SQL queries to analyze the data.
3. Retrieved relevant information from the dataset.
4. Examined patterns in the results.

Insights can be added after executing the SQL queries and reviewing the results.

## Conclusion
This project demonstrates how SQL can be used to explore and analyze cirrhosis patient data.
